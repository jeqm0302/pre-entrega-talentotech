# Pixel Arena — Pre-Entrega Front-End (Talento Tech)

Sitio web de una tienda ficticia de periféricos y accesorios gamer, desarrollado con HTML y CSS como pre-entrega del curso de Front-End de Talento Tech.

## Sitio publicado

https://pixel-arena-jesus.netlify.app
(Usamos esta plataforma por tener problemas con git)

## Propósito

Presentar los productos de la tienda, mostrar reseñas de clientes y ofrecer un formulario de contacto funcional, aplicando estructura semántica, estilos con CSS y diseño responsivo.

## Contenido del sitio

- **Productos:** cards con imagen, descripción y precio, organizadas con Flexbox.
- **Reseñas:** opiniones de clientes organizadas con CSS Grid.
- **Video:** video de YouTube integrado mediante iframe.
- **Contacto:** formulario con campos de nombre, correo electrónico y mensaje, enviado a través de Formspree.
- **Navegación:** lista desordenada con enlaces internos a cada sección.

## Tecnologías

- HTML5 semántico (header, nav, main, section, footer)
- CSS3 en archivo externo (Flexbox, Grid, Media Queries, degradados)
- Google Fonts (Orbitron y Roboto)
- Formspree para el envío del formulario
- Netlify para el hosting

## Diseño responsivo

En pantallas de hasta 768 px, la navegación pasa a columna, las cards y reseñas se muestran de a una por fila y el formulario de contacto ocupa todo el ancho de la pantalla.

## Cómo verlo localmente

1. Clonar o descargar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir `index.html` con la extensión Live Server.
