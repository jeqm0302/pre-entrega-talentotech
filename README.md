# Pixel Arena — Pre-Entrega Front-End (Talento Tech)

Sitio web de una tienda ficticia de periféricos y accesorios gamer, desarrollado con HTML y CSS como pre-entrega del curso de Front-End de Talento Tech.

## Propósito
Presentar los productos de la tienda, mostrar reseñas de clientes y ofrecer un formulario de contacto funcional.

## Tecnologías
- HTML5 semántico
- CSS3 (Flexbox, Grid, Media Queries)
- Google Fonts
- Formspree para el formulario de contacto
